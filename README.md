## 🚧 Featured Projects

Everything below is live. Full write-ups are on [mycodedojo.com](https://www.mycodedojo.com/#work).

### 🔴 [Shuin](https://shuin.mycodedojo.com) · [code](https://github.com/mcooper7649/shuin)  
_Multichain NFT minter and collection launcher with fully on-chain art._

- Images are compressed in the browser and written into contract bytecode (SSTORE2); `tokenURI` returns a data URI, so there's no IPFS link to rot. Live on **Base mainnet**.
- Creators launch their own collections with price, supply cap, mint window, Merkle allowlist, ERC-2981 royalties and optional soulbound mode.
- **Solidity**, **Foundry**, **OpenZeppelin**, **Next.js**, **TypeScript**, **wagmi/viem**; CREATE2 deploys give one address on every chain.

### 📈 [FloorFeed](https://floorfeed.mycodedojo.com) · [code](https://github.com/mcooper7649/floorfeed)  
_FOMO-style social trading app for NFTs._

- Streams real sales from 74 collections on Solana, Ethereum, Base and Polygon, ranks wallets by realized profit, and has an AI model explain notable trades in plain English.
- Collection pages chart sales against the floor and listing depth; one-tap paper trading.
- **React Native / Expo Router**, **TypeScript**, **Node.js + Fastify**, **SQLite**, **Claude API**, **Ollama**.

### 🎨 [Kasane](https://kasane.mycodedojo.com) · [code](https://github.com/mcooper7649/kasane)  
_Accessible color scales for design systems, built in OKLCH._

- Turns one color (or an image) into a six-role palette of 11-step scales, with WCAG contrast ratings and a live light/dark UI preview.
- Exports to Tailwind v4/v3, CSS variables, SCSS and W3C design tokens. Color math (gamut mapping, k-means extraction) written from scratch and tested with Vitest.
- **React 19**, **TypeScript**, **Vite**.
